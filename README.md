
# Student Mark and Grade Calculator

## 1. Project Overview
The Student Mark and Grade Calculator is a simple application
developed using the C programming language. It calculates the
total marks, average and grade of a student based on marks
entered for five subjects.

## 2. Objective
To develop a C program that automates student mark calculation
and grade assignment using conditional statements and loops.

## 3. Features
- Accepts marks for five subjects.
- Validates marks between 0 and 100.
- Calculates total marks out of 500.
- Calculates the average.
- Displays the grade based on the average.

## 4. Programming Concepts Used
- Variables and data types
- Input and output functions
- Arrays
- For loop
- If-else statements
- Arithmetic operators

## 5. Sample Output
Total Marks: 433 / 500
Average: 86.60
Grade: A

## 6. How to Run
1. Download the main.c file.
2. Open it using a C compiler.
3. Compile and run the program.
4. Enter the marks for five subjects.
